# ধানের দেশ – Bangladeshi Rice Variety Guide

A Bangla-language guide to BRRI rice varieties (BRRI dhan29, BRRI dhan88):
growth duration, harvest, care and fertilization.

**Live:** https://bridhan.netlify.app

## Tech
React, Vite, React Router, Tailwind CSS, Framer Motion

## What I practiced
- Data-driven pages: one `Variety` component renders any entry from `varieties.js`
- Dynamic routes with `useParams`
- Accessible dropdown built with `useState`, `useRef`, `useEffect`
- Staggered and looping animations with Framer Motion (reduced-motion supported)

## Run locally
npm install
npm run dev
